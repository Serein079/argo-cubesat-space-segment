# Attribution and external dependencies

The original assessment uses Princeton Satellite Systems (PSS) Spacecraft Control Toolbox and course tutorial/starter workflows. Orbit/environment functions, numerical helpers and SCT visualisation routines are external dependencies. Their authorship is not attributed to the student.

The public package does not bundle:

- `SCTAcademic/` toolbox libraries or their documentation;
- course `SCT/` tutorials and `MissionStarter/` framework;
- lecture slides, exam/quiz materials, rubric PDFs, reference papers or the AMSAT-IARU workbook;
- `Draft Report Code/DataRateGain_v2.m` (explicit PSS 2020 copyright header);
- `Draft Report Code/W09_Tut_LinkOrbitAnalysis.m` (explicit PSS 2009 copyright header).

The last two files remain unchanged in the separate local archive. Other MATLAB files are presented as mission-specific/course-adapted work; absence of a copyright header is not a claim that every line is independently authored. Dependency checks and report images do not grant rights to redistribute the toolbox.

The local toolbox contains `Documentation/SoftwareLicense.pdf`; obtain your own authorised installation for use. This repository intentionally assigns no blanket MIT/Apache licence to the mixed-origin snapshot. Existing notices and ownership continue to apply.

Original assessment reports remain local, including their original bibliographies and identity fields. The public portfolio uses extracted project-result figures and paraphrased context. Packaging documentation was prepared with AI assistance in October 2026; original code and results were not rewritten.
